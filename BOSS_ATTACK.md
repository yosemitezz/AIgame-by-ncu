# Boss Attack Rhythm Subproject

This top-level marker points to the independent Godot project in `boss_attack/`.

It is stacked on the latest `integrate/vfx-primary` commit and does not replace the existing Bellkeep project. The normal four moves, accelerated action phrases, fixed cube attack and four geometric laser formations are implemented from the follow-up design. Boss and skill textures remain empty.

Open `boss_attack/project.godot` with Godot 4.7.
