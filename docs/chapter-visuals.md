# Chapter visual adapters

Three new presentation-only nodes accompany the data-driven chapter runner. Original pixel drawing, no imported raster source or 3D input; existing Fusion Pixel12px font and its license are reused.

- `presentation/flying_eye.gd`: `configure(game, hero)`, `update_story(state)`, `snap_to_hero()`. It follows behind/above the actual hero, with bounded teleport recovery, pupil movement, slow blink and articulated eyelid fins. Friendly/concerning/cold looks share the same original eye drawing. World eye is hidden during full-black/terminal scenes and after `ending_dismissed`; replay can reveal it again through the state owner. It writes no hero property.
- `presentation/corruption_aura.gd`: `configure(hero)`, `update_story(state)`. Zero corruption draws nothing. Unique-kill progress controls at most14 small edge wisps; only the highest boss-complete intensity adds two narrow rising ribbons and a broken floor trace. The central armour/face stays open, local bounds62x76px, no screen-wide mask or hurtbox/physics changes.
- `ui/chapter_overlay.gd`: `update_state(state)`, `set_suspended(paused)`. A full-rect nearest-pixel `Control`, `PROCESS_MODE_PAUSABLE`, mouse-ignore, no input capture. Root owns advance/skip/replay/return keys and supplies accurate `hint`. Hide it through `set_suspended(true)` when opening the existing pause menu.

Shared state: `phase` opening/explore/rescue/aftermath/betrayal/narrative_dead; `blocking`, `line`, `line_id`, `speaker`, `eye_mood`, `corruption`, `blackout`, `faint`, `eye_closeup`, `dizzy`, `node_elapsed`, `death_elapsed`, `bloodred`, `narrative_dead`, `chapter_complete`, `can_skip`, `ending_dismissed`, `hint`.

Nonblocking teaching uses a compact top dialogue strip and never captures a key or freezes combat. Root should suppress its old same-position narration while this strip is populated. Blocking scenes use a lower100px panel, gradual darkness and restrained star drift; no full-white flash/strobe. The ending dimming now also tightens nested edge bands inward like closing vision, and the last close-up beat fades the eye out through its `faint` cursor before the death broadcast. The real `betray_blackout` interpolation remains visible; only a data node with `eye_closeup:true` reveals the enlarged narrowed eye after full black, before the death broadcast. The terminal broadcast has a black ground, red48px data-driven title(default `你死亡`) at the original death-title baseline, nine independently growing2–3px blood trails below the letters, and state-provided return/replay instructions. The small completion label is empty by default; the retained chapter result is gameplay state, not a vessel/identity reveal. Existing normal defeat HUD is untouched.

Terminal blood reads `death_elapsed` from the real paused chapter clock. A fallback presentation clock is pausable; it does not alter story/music time. Tests exercise the actual `boss_defeated -> skip -> tick -> presentation` seam, not just an artificial nonzero timestamp. The ending can therefore be skipped directly and still grow blood correctly; pause freezes it.

Validation: `tests/chapter_visual_test.gd` checks clean/aura budgets, bounded edge-only fragments, live companion isolation, death colour separation, blood bounds, pause, font glyphs and actual terminal timing. `tools/capture_chapter_story.gd` captures six800x450fixed frames with all AI/physics/audio/input playback disabled. `04-corrupted-after-boss` intentionally unmasks the aura for a before/after art comparison; its manifest names that fixture adjustment. `clean-corruption-detail.png` is a nearest-neighbour detail comparison, not a new production asset.

Evidence lives under ignored `artifacts/chapter-story/`. Static frames establish layout and pixel contrast, not continuous gameplay feel or final authored wording. All displayed story dialogue is replaceable data owned by the state graph; this adapter adds no character identities, history or relationship canon.
Latest user direction keeps the original confirmed chapter. No black-thread extraction, controlled finishing stroke, possession-fusion diagram, five-year memory or vessel-complete label is rendered here. Those discarded friend suggestions do not become canon through this adapter.
