# Third-party and user-supplied assets

The repository's original MIT license covers the source code created for this branch.

`audio/if_infinity.ogg` (transcoded from the user-supplied `IF = Infinity.flac`) and `data/if_infinity.chart.json` were supplied by the user for this private project. Their names, authorship, and redistribution rights were not supplied with this handoff. They are therefore excluded from the MIT license grant of the source code and must be reviewed before public distribution.

No assets from `game2` are included.
